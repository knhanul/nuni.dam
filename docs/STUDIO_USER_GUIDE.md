# 누니담(NuniDam) 오프라인 웹 관리 시스템 사용 설명서 (`docs/STUDIO_USER_GUIDE.md`)

누니담 스튜디오(NuniDam Studio)는 별도의 클라우드, 외부 서버, 인터넷 연결이나 회원 가입 없이 **같은 내부 Wi-Fi에 연결된 PC 또는 스마트폰 웹브라우저에서 태블릿의 사진 앨범, 명언·시, 재생 장면, 요일별 시간표를 편집**하는 내장 관리 시스템입니다.

---

## 1. 태블릿에서 원격 관리 켜기

1. 태블릿에서 **누니담** 앱을 실행합니다.
2. 하단 또는 좌측 메뉴에서 **설정(`SETTINGS`)** 탭을 선택합니다.
3. 설정 그룹 맨 위의 **원격 관리 (누니담 스튜디오)**를 누릅니다.
4. **원격 관리 켜기 (내장 웹서버 활성화)** 스위치를 켭니다.
   - 초기 상태에서는 보안을 위해 비활성화되어 있습니다.
   - 활성화하면 화면에 **접속 가능한 IP 주소와 포트**(예: `http://192.168.0.25:8787`), **QR 코드**, 그리고 **6자리 일회용 페어링 코드**가 표시됩니다.
5. 추가 보안을 원하면 **관리자 인증 비밀번호(PIN) 설정**을 눌러 비밀번호를 지정할 수 있습니다(평문으로 저장되지 않고 암호화 해시로만 저장됩니다).

---

## 2. PC 또는 스마트폰에서 웹 관리자 접속

1. PC 또는 스마트폰을 태블릿과 **동일한 내부 Wi-Fi 공유기**에 연결합니다(외부 인터넷 연결은 없어도 됩니다).
2. 스마트폰에서는 태블릿 화면의 **QR 코드**를 카메라로 스캔하거나, PC 웹브라우저 주소창에 표시된 접속 주소(예: `http://192.168.0.25:8787`)를 입력합니다.
3. 연결 화면이 나타나면 태블릿에 표시된 **6자리 일회용 페어링 코드**(및 설정한 경우 관리자 PIN)를 입력하고 **연결하기**를 누릅니다.

---

## 3. 앨범 만들기 및 사진 업로드

1. 좌측 메뉴에서 **2. 앨범 · 사진**으로 이동합니다.
2. **+ 새 앨범 만들기**를 눌러 `아침 풍경`, `가족의 시간`, `여행의 추억` 등 원하는 앨범을 생성합니다.
3. 앨범 이름, 설명, 정렬 기준(`지정한 순서`, `최근 촬영일 순`, `이름 순`), 기본 전환 시간, 무작위 재생 여부를 설정하고 **앨범 정보 초안 저장**을 누릅니다.
4. **사진 업로드** 영역에 PC나 스마트폰의 사진 여러 장을 드래그 앤 드롭하거나 **사진 파일 선택**으로 업로드합니다.
   - 업로드 진행률, 취소, 실패한 파일만 재시도하기를 지원합니다.
   - 동일한 사진(SHA-256 해시 기준)은 기기에 중복 저장되지 않으며, 한 장의 사진을 여러 앨범에 **선택 사진 다른 앨범에 추가**로 자유롭게 참조할 수 있습니다.
   - 원하는 사진을 선택한 뒤 **대표 사진 지정**을 눌러 앨범 커버를 지정할 수 있습니다.

---

## 4. 명언 및 시 등록 · 글귀 모음 만들기

1. 좌측 메뉴에서 **3. 명언 · 시 · 글귀**로 이동합니다.
2. **+ 새 글귀 등록**을 누르고 제목, 종류(`명언`, `시(詩)`, `직접 작성한 글`, `짧은 문장`, `기념일 메시지`), 카테고리(`아침의 명언`, `행복`, `사랑`, `위로`, `인생`, `계절의 시`, `가족`, `직접 작성한 글`), 작가, 출처, 태그, 본문을 입력한 뒤 **글귀 초안 저장**을 누릅니다.
   - 긴 시(詩)는 글자 크기를 무리하게 줄이지 않고 줄바꿈과 문단을 유지한 채 자동으로 페이지를 나누어 표시합니다.
3. 좌측의 **글귀 모음(Collections)**에서 카테고리나 종류별로 글귀 묶음(예: `긍정적인 아침 명언`, `계절과 저녁의 시`)을 만들어 장면에 연결할 수 있습니다.

---

## 5. 재생 장면(Scene) 만들기

1. 좌측 메뉴에서 **4. 재생 장면(Scene)**으로 이동합니다.
2. **+ 새 장면 만들기**를 누르거나 기본 제공 장면(`좋은 아침`, `가족의 시간`, `저녁의 쉼`, `야간 절전`)을 선택합니다.
3. 다음 항목을 조합합니다:
   - **레이아웃 템플릿**: `전체 화면 사진`, `감성형 스마트 매거진`, `생활 보드(시계·달력)`, `글귀 전용 화면`
   - **글귀 표시 방식**: `사진 위 글귀 표시`, `사진·글귀 분할 화면 배치`, `글귀 전용 중심 화면`, `표시하지 않음`
   - **배경 색감 테마**: `밀크`, `세이지`, `잉크`
   - **전환 효과 및 표시 시간**: `부드러운 확대(ZOOM)`, `차분한 전환(FADE)`, `효과 없음(NONE)`, 사진 표시 시간(초), 사진 N장마다 글귀 1회 표시 빈도, 화면 밝기(%)
   - **연결할 사진 앨범 및 글귀 모음**: 복수 앨범 혼합 재생 지원
4. 좌측 하단의 **실시간 화면 미리보기**에서 **가로형 / 세로형** 버튼을 눌러 태블릿 화면 방향별 예상 모습을 확인하고 **장면 초안 저장**을 누릅니다.

---

## 6. 요일별 · 시간대별 시간표 지정

1. 좌측 메뉴에서 **5. 주간 편성표**로 이동합니다.
2. **+ 새 편성 규칙 추가**를 누르고 일정 이름, 편성 종류, 재생할 장면, 시작/종료 시간, 요일(`매일`, `평일`, `주말` 또는 개별 요일)을 선택합니다.
   - **편성 우선순위**: `1순위: 임시 즉시 재생` > `2순위: 특정 날짜 / 생일·기념일 편성` > `3순위: 요일별 반복 편성` > `4순위: 기본 장면`
   - **자정 통과 일정 지원**: 예를 들어 `22:00 ~ 06:00`으로 설정하면 밤 10시부터 다음 날 아침 6시까지 야간 절전 장면이 정상 작동합니다.
   - 같은 우선순위에서 시간이 겹치면 상단에 즉시 **시간표 겹침 알림**이 표시됩니다.

---

## 7. 태블릿에 적용 및 독립 재생

1. 편집한 내용은 먼저 초안으로 저장됩니다.
2. 우측 상단의 **태블릿에 적용** 버튼을 누르면 시간표 충돌 여부를 검증하고 태블릿 재생 엔진에 즉시 반영됩니다.
3. 적용이 끝난 뒤에는 **PC를 끄거나 Wi-Fi 공유기 전원을 꺼도 태블릿이 내장된 편성표와 사진·글귀 데이터베이스를 기준으로 24시간 독립 재생**합니다.

---

## 8. 오프라인 백업 및 복원 (`.nunidam` 패키지)

1. 웹 스튜디오의 **6. 기기 · 백업** 탭(또는 태블릿의 **설정 → 설정 옮기기**)을 엽니다.
2. **.nunidam 패키지 다운로드**(전체 백업 또는 특정 앨범 선택 내보내기)를 누르면 `manifest.json`, `albums.json`, `texts.json`, `scenes.json`, `schedules.json`, `photos/`, `checksums.json`이 포함된 단일 `.nunidam` 파일이 저장됩니다.
3. 다른 태블릿이나 초기화 후 복원할 때는 **패키지 가져오기 (복원)**에서 `.nunidam` 파일을 선택하고 **검증 후 패키지 복원 실행**을 누르면 SHA-256 체크섬과 매니페스트를 검증한 뒤 안전하게 복원됩니다.
