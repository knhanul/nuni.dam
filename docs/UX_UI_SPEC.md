# UX·UI 및 적응형 레이아웃 사양 (`docs/UX_UI_SPEC.md`)

## 1. 제품 경험과 정보 구조

### 1.1 감상(Playback)과 관리(Management)의 분리
- **감상 모드 (`FrameActivity`, `NuniDream`)**: 사진과 사용자가 선택한 정보(시계·촬영일·명언/시)만 전체 화면에 표시합니다. 탐색 메뉴·설정 항목·디버그 상태는 숨기며, 화면을 터치하면 하단 제어 시트가 나타나고 조작이 없으면 5초 후 자동으로 닫힙니다(접근성 서비스 활성 또는 포커스 보유 시 자동 숨김 해제).
- **관리 모드 (`MainActivity`)**: 최상위 목적지를 **액자(`FRAME`) / 사진(`PHOTOS`) / 꾸미기(`CUSTOMIZE`) / 설정(`SETTINGS`)** 4개로 통일했습니다.

### 1.2 창 너비(Window Size Class) 기반 반응형 구성
태블릿 모델명이나 물리 해상도가 아니라 실제 창 너비(`screenWidthDp`)와 가용 높이를 기준으로 분기합니다.

| 창 너비 구간 | 탐색 구조 | 본문 구성 | 바깥 여백 |
|---|---|---|---|
| **600dp 미만** | 하단 탐색 바 (4개 탭) | 단일 본문. 사진 상세·설정 그룹은 모달 시트/대화상자로 표시 | `16dp` |
| **600 ~ 839dp** | 좌측 탐색 레일 (`96dp`) | 단일 본문, 반응형 3열 사진 그리드 | `24dp` |
| **840dp 이상** | 좌측 탐색 레일 (`96dp`) | **2-Pane 분할**: 액자(미리보기 + 행동), 사진(그리드 + 우측 상세 편집), 꾸미기(좌측 고정 미리보기 + 우측 옵션), 설정(좌측 그룹 목록 + 우측 상세 패널) | `32dp` |

- `WindowInsets`는 최상위 셸(`MainActivity`, `FrameActivity`)에서 한 번만 적용하여 하단 탐색 바와 시스템 내비게이션 바 여백이 중복되지 않도록 했습니다.

## 2. 시각 디자인 토큰 (`Ui.java`, `styles.xml`)

‘사진집과 작은 갤러리’의 차분하고 따뜻한 인상을 주는 디자인 토큰을 공통 적용했습니다.

| 토큰 이름 | 색상 코드 | 용도 및 대비 |
|---|---|---|
| `BG` (`background`) | `#F4F2EC` | 따뜻한 기본 배경 |
| `SURFACE` (`surface`) | `#FFFFFF` | 주요 카드·편집 패널·탐색 바 배경 |
| `SURFACE_SUBTLE` (`surfaceSubtle`) | `#E8EDE5` | 선택된 탭·보조 버튼·아이콘 배지 배경 |
| `INK` (`textPrimary`) | `#24332B` | 제목·본문 (`#F4F2EC` 대비 11.4:1, WCAG AAA 통과) |
| `MUTED` (`textSecondary`) | `#626D65` | 보조 설명·요약값 (`#FFFFFF` 대비 5.1:1, WCAG AA 통과) |
| `PRIMARY` (`primary`) | `#365B46` | 주요 행동 버튼·선택 강조 (`#FFFFFF` 대비 7.6:1) |
| `ON_PRIMARY` (`onPrimary`) | `#FFFFFF` | 주요 버튼 글자 및 아이콘 |
| `OUTLINE` (`outline`) | `#CDD4C9` | 카드·입력창·구분선 테두리 (단독으로 선택 상태를 표시하지 않고 배경색·굵기·체크 표시와 병행) |
| `DANGER` (`danger`) | `#A64932` | 영구 삭제·오류 안내 |
| `DARK_BG` / `DARK_TEXT` / `DARK_SECONDARY` | `#18221D` / `#EDEFE8` / `#B5BFB4` | 잉크(어두운) 테마 배경·본문·보조 텍스트 |

- **타이포그래피와 터치 영역**:
  - 화면 제목 `26sp`, 섹션 제목 `18sp`, 본문 `16sp`, 설명 `14sp`.
  - 모든 조작 버튼 최소 터치 영역 `48×48dp`, 핵심 주요 행동 버튼 높이 `56dp` 이상.
  - 액자 위 시계·문구 글자 크기는 꾸미기 탭에서 `100% / 120% / 140%` 별도 배율(`fontScale`)을 지원합니다.

## 3. 화면별 상태 및 오류 UX

| 화면 | 정상 / 빈 상태 / 오류 처리 |
|---|---|
| **액자 탭** | • **사진 있음**: 실제 `FrameView` 렌더러를 공유하는 큰 미리보기 + `액자 시작` 주요 버튼 + 현재 구성/사진 수/야간 시간표 요약.<br>• **사진 0장(첫 사용)**: 예시 미리보기 배지(`예시 화면 미리보기 · 보관함에 추가되지 않음`) + `이 기기에서 사진 선택` / `스마트폰에서 보내기 · QR` / `자동 동기화 폴더 선택` 온보딩 제공.<br>• **가져오기 일부 실패**: 성공·실패 장수와 실패 사유를 알리고 **실패한 파일만 재시도** 버튼 제공. |
| **전체 화면 감상** | • **감광 중 터치 보호**: 야간 또는 부재 감광(`DIMMED`) 상태에서 첫 터치는 메뉴를 열거나 다른 동작을 실행하지 않고 화면 밝기만 즉시 복귀시킵니다.<br>• **구도 보호**: 단체 사진 얼굴이 잘리거나 얼굴이 없으면 전체 보기(`contain`)로 표시하며, 수동 중심점 지정 및 자동 구도 초기화를 지원합니다. |
| **사진 탭** | • 창 너비별 2/3/4열 반응형 썸네일 그리드.<br>• `전체 / 즐겨찾기 / 휴지통` 필터 및 다중 `선택` 모드(선택 개수 표시, 일괄 즐겨찾기·휴지통 이동·복원·`N장 영구 삭제` 확인).<br>• 즐겨찾기 필터 결과가 0장일 때 필터 해제 안내 문구 표시. |
| **꾸미기 탭** | • 상단/좌측에 실제 `FrameView` 미리보기를 고정하고, `화면 구성 → 색감 → 시계·날짜·문구 → 사진 전환` 순으로 편집.<br>• 임시 변경(`FrameView.Config`)은 즉시 미리보기에만 반영하며, **`적용`** 클릭 시 영구 저장하고 **`취소`** 클릭 시 이전 설정으로 복원합니다. |
| **설정 탭** | • 6개 그룹(`화면과 절전`, `사진 보관`, `액자 실행`, `설정 옮기기`, `고급`, `앱 정보`)과 현재 요약값 행으로 정리.<br>• 꾸미기 항목을 중복 배치하지 않고 꾸미기 탭으로 연결. 숫자 입력 오류는 입력란 바로 옆에 단위(`MB`, `%`)와 함께 표시. |
| **QR 전송** | • 태블릿 전경 실행 중 `FLAG_KEEP_SCREEN_ON`으로 절전 화면 꺼짐을 방지하며, 연결 대기/승인 요청/승인 완료/만료 상태를 실시간 배지로 표시.<br>• 스마트폰 웹(`transfer.html`)도 동일한 디자인 토큰(`#F4F2EC`, `#365B46`, `#24332B`)과 실패 파일 재시도 UX를 공유합니다. |

## 4. 접근성(Accessibility) 지원
- 모든 조작은 단일 탭(터치)으로 수행 가능하며 숨은 제스처나 길게 누르기 전용 기능을 두지 않았습니다.
- 탐색 탭에 `setSelected(true)` 및 `contentDescription`을 부여하고, 설정 요약 행은 제목과 현재 요약값을 함께 읽도록 구성했습니다.
- 시계 분 단위 갱신이나 카메라 프레임 분석 이벤트가 발생할 때마다 접근성 알림(LiveRegion/Announcement)을 발생시키지 않습니다.
- TalkBack 등 접근성 서비스가 켜져 있거나 제어 버튼에 포커스가 있을 때는 전체 화면 제어 시트의 5초 자동 숨김 타이머를 작동시키지 않습니다.
