# 실기기 시험 및 출시 전 확인

아래 항목은 **아직 실행 완료로 표시하지 않은** 수동 검증 목록입니다. 자동 검사의 실제 결과는 `VERIFICATION.md`에 기록합니다.

## 기기와 화면

- [ ] Android 6(API 23) 저메모리 기기, 중간 버전 태블릿, Android 16(API 36)에서 설치·첫 실행
- [ ] 가로/세로, 4:3/16:10/16:9, 7~12인치, 시스템 글자 확대, 화면 가장자리·메뉴 잘림
- [ ] 사진 액자/스마트 매거진/생활 보드와 밀크/잉크/세이지 조합
- [ ] 화면 탭, 이전/다음, 일시 정지, 화면 회전, 백그라운드 복귀, 날짜·시간대 변경
- [ ] 저사양 모드에서 72시간 재생, 메모리 증가·ANR·발열·CPU·배터리 관찰

## 사진과 보관

- [ ] EXIF 8방향, 세로·가로·정사각형, 단체 사진, 얼굴 없음, 작은 얼굴
- [ ] 얼굴 머리 위 여백, 여러 얼굴 크롭 불가능 시 전체 보기, 수동 중심점 및 자동 복원
- [ ] 잘못된 이미지·특수 파일명·큰 이미지·40 MiB 경계·디스크 부족
- [ ] 일괄 가져오기 중 회전·앱 종료, 중복 원본, 끊긴 입력, `.part` 잔여 정리
- [ ] 휴지통 복원·영구 삭제, 직접 가져온 사진/즐겨찾기의 자동 삭제 보호
- [ ] 촬영일 수정, N년 전 오늘, 빈 앨범, 즐겨찾기 전용 모드의 빈 결과
- [ ] 앱 제거 시 원본은 남고 앱 사본은 사라지는지 확인

## QR와 네트워크

- [ ] 같은 개인 Wi-Fi의 실제 스마트폰 브라우저에서 QR 승인·연속 업로드
- [ ] 미승인/거절/잘못된 토큰/만료 토큰으로 사진 API 접근 차단
- [ ] QR 재생성·화면 이탈 시 이전 세션 차단, 앱 전환·회전·IP 변경
- [ ] 파일 크기·길이 불일치·이미지 아닌 파일·Origin 불일치·동시 요청 제한
- [ ] 끊김 후 실패 사진 재시도, 24장 페이지 이동·썸네일 요청·기록·휴지통
- [ ] 폴더 제공자의 빈 목록·부분 로딩·권한 만료·중단·원본 변경·원본 삭제
- [ ] 오래된 원본 버전 보존 및 원본이 남은 영구 삭제 사진의 재수집 동작 확인
