# 검증 기록 (`docs/VERIFICATION.md`)

이 문서는 개발 환경에서 실제 실행하여 통과한 자동 검사와, 물리 태블릿·전력 측정 장비가 필요하여 **미검증**으로 남겨둔 항목을 명확히 구분합니다.

## 1. 검증 환경 및 실행 명령

- **실행 환경**: Windows 11 (`win32`), OpenJDK 17, Gradle 8.13, Android Gradle Plugin 8.11.1, `compileSdk 36` / `targetSdk 36` / `minSdk 23`, Build Tools 35.0.0, Node.js (내장 웹 스크립트 구문 검사용)
- **연결된 실기기/에뮬레이터 확인**: `adb devices` 실행 결과 연결된 Android 기기 없음 (`List of devices attached` 비어 있음). 따라서 실기기 화면 캡처 및 하드웨어 센서·전력 실측은 수행하지 않았으며 목업 이미지를 실기기 캡처로 대체하지 않았습니다.

### 실행한 검증 명령

```bat
./gradlew.bat clean :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
node --check app/build/tmp_check.js
```

### 단위 테스트(`CoreTest.java`) 검증 범위 (총 28개)
1. **기존 21개 회귀 테스트 유지**:
   - 자정 경계 야간 시간 판정, 시작=종료 비활성화, 주간 경계, 잘못된 시각 문자열 검증
   - QR 세션 토큰 일치·만료·회전
   - 얼굴 미검출/원거리 다중 얼굴 시 전체 보기(`contain`), 수동 초점 경계, 3,000회 무작위 얼굴·확대 시나리오, 비정상 얼굴 좌표 폴백
   - 디코딩 전 샘플링 비율 계산 및 비정상 해상도 거절
   - 저장 용량 상한·여유 공간·오버플로 방지
   - 불완전/오류/빈 폴더 동기화 시 삭제 금지, 수동 보관/즐겨찾기/참조 사진 보호
   - 스트림 최대 크기 제한 및 `ExactStream` 정밀 바이트 읽기
2. **명언·시 및 주기 테스트 (2개)**:
   - `POEM|본문|작가` 인코딩·디코딩, 줄바꿈 복원, 카테고리 필터(`ALL`, `QUOTE`, `POEM`, `NONE`)
   - 전환 주기(`PHOTO`, `MINUTES_15`, `HOUR`, `DAY`) 인덱스 계산
3. **절전 상태 제어기 및 카메라 ROI 밝기 변화 테스트 (5개)**:
   - `ACTIVE → IDLE_PENDING → DIMMED` 상태 전이와 깨어난 뒤 최소 30초 유지(`MIN_HOLD_MS`)
   - 야간 시간표 우선 적용(`reactAtNight=false`일 때 야간 움직임 무시) 및 사용자 터치 시 60초 임시 밝기 복귀
   - 카메라 오류(`ERROR`) 시 부재(`DIMMED`)로 오인하지 않고 `ACTIVE` 유지, 권한 철회(`PERMISSION_DENIED`) 시 `UNAVAILABLE` 전이
   - 메뉴 조작·편집·전송 중 절전 억제(`inhibited`) 및 미검증 기기에서 `SCREEN_OFF` 허위 기록 방지
   - `Core.lumaMotionScore`의 전체 평균 밝기 변화(`meanShift`) 보정(자동 노출·화면 반사 오탐 방지) 및 관심 영역(ROI) 외부 움직임 무시·내부 움직임 검출

## 4. 미검증 항목 (필요한 환경 명시)

다음 항목은 현재 빌드 컨테이너에 물리 Android 태블릿과 전력 측정 장비가 연결되어 있지 않아 실행하지 않았으며, 출시 전 실기기 환경에서 확인해야 합니다.

1. **실기기 화면 캡처 및 레이아웃/글자 크기(100/130/200%) 육안 검수** — *미검증 (필요 환경: Android 6.0~16 실제 태블릿 또는 에뮬레이터)*
2. **실제 전면 카메라를 통한 보행자 접근·창문 조명 변화·정지 인물 감지율 및 발열 측정** — *미검증 (필요 환경: 전면 카메라 장착 태블릿 및 다양한 실내 조명 환경)*
3. **화면 완전 종료(`Display.STATE_OFF`) 후 카메라/센서 이벤트 수신 및 잠금 없이 화면 자동 복귀 반복 시험** — *미검증 (필요 환경: 대상 태블릿 실기기 및 OS 전원 정책 확인)*
4. **전력계(Wh)를 이용한 조건 A(상시 재생) / B(감광) / C(카메라 감지) / D(화면 꺼짐) 소비 전력 실측** — *미검증 (필요 환경: USB/DC 인라인 전력계 및 동일 밝기·배터리 통제 환경)*
5. **실제 스마트폰 Wi-Fi QR 스캔·다중 사진 연속 업로드 및 24~72시간 무인 구동 시험** — *미검증 (필요 환경: 동일 사설 Wi-Fi에 연결된 스마트폰 + 태블릿)*
