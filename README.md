# 누니담 · nuni dam

**눈부신 순간을 담다. 서랍 속 안드로이드 태블릿을 우리만의 액자로.**

로컬 사진 보관, 스마트폰 QR 전송, 온디바이스 얼굴 분석과 네이티브 액자 화면을 구현한 Android Studio 프로젝트입니다. Java 17 기반이며 최소 Android 6.0(API 23)을 지원 대상으로 합니다.

**버전 0.1.0은 개발·시험용 첫 구현입니다. 원안의 모든 기능이 완성된 상용 출시판은 아닙니다.** 실제 Play 결제, 외부 사진 서비스 전용 API, 일정 연동, 카메라 감지 등은 포함하지 않습니다. 아래 구현 범위와 `docs/RELEASE_CHECKLIST.md`를 확인하세요.

## 바로 실행하기

1. 태블릿에서 `builds/nunidam-0.1.0-debug.apk`를 열어 설치합니다. 설치 출처 허용은 태블릿 안내를 따릅니다. 개발용 서명 APK입니다.
2. 첫 화면의 **이 기기에서 사진 선택**으로 JPEG/PNG 사진을 가져옵니다.
3. 스마트폰에서 보내려면 두 기기를 같은 개인 Wi-Fi에 연결하고 태블릿에서 **스마트폰으로 사진 보내기 · QR**을 엽니다.
4. 스마트폰으로 QR을 스캔한 다음 **태블릿에서 연결을 승인**합니다. 스마트폰 브라우저에서 사진을 추가하고 문구·즐겨찾기·화면 분위기를 바꿀 수 있습니다.
5. 전송 화면을 닫고 **액자 시작하기**를 누릅니다. 화면을 터치하면 이전/다음·일시 정지·설정 메뉴가 나타납니다.
6. 구형 기기가 느리면 **설정 → 저사양 모드**를 켜고 새 사진을 가져옵니다.

QR 화면을 닫거나 앱을 다른 화면으로 전환하면 서버가 중지됩니다. QR 연결은 20분 후 만료됩니다. 게스트 Wi-Fi의 기기 간 통신 차단, VPN, IPv6 전용망에서는 연결되지 않을 수 있습니다. 스마트폰 전송 페이지는 최신 브라우저 사용을 권장합니다.

| 장시간 표시 보조 | 야간 감광, 15분 간격 문자 위치 이동, 저사양 정지 모드 |
| 재부팅 진입 | 시작 알림, 선택 가능한 기본 홈 진입점. 잠금·제조사 정책에 따라 동작 |
| 설정 배포 | 버전·값 검증을 거치는 JSON 내보내기·가져오기 |

### 원안과 달라진 부분 / 후속 구현

- **Google Photos·NAS·클라우드 앨범 전용 연결은 미구현**입니다. 현재 수집원은 직접 선택한 사진, QR 업로드, SAF 폴더입니다. 폴더 제공자가 클라우드를 지원하는 경우에도 해당 제공자의 권한·목록 완전성·오프라인 동작에 의존합니다. Wi-Fi 조건을 가진 클라우드 다운로드 작업과는 다릅니다.
- **사진 저장소를 용량 초과 시 자동 LRU 삭제하지 않습니다.** 직접 넣은 사진을 잃지 않도록 새 가져오기를 거절합니다. 휴지통도 보관 용량에 포함됩니다. 용량 상한 변경 또는 영구 삭제로 공간을 확보하세요. 썸네일 메모리 캐시만 LRU입니다.
- **생활 보드의 달력은 현재 월 표시입니다.** `.ics` 및 기기 일정 읽기, 커스텀 폰트는 미구현입니다.
- **화면을 실제로 끄고 카메라로 깨우는 기능은 없습니다.** 야간에는 밝기와 검은 오버레이를 사용합니다. 조도 센서·카메라 모션 감지·Device Owner 키오스크는 후속 항목입니다.
- **일반 앱 권한에서 강제 자동 실행·크래시 재시작을 보장하지 않습니다.** 부팅 알림, 선택한 기본 홈, 마지막 사진 복원으로 대응합니다. 강제 종료 뒤 무조건 되살리는 Watchdog은 넣지 않았습니다.
- **실제 Play Billing, Pro 구매·복원, 무료 100장 제한은 미구현**입니다. 개발용 버전은 구현된 기능을 모두 사용할 수 있습니다. 저장 공간·폴더당 5,000장 등 기술적 제한은 있습니다. `docs/MONETIZATION.md`에 출시 전 연결 지점을 정리했습니다.
- 수백 개의 인용 명언 대신 **저자를 허위 표기하지 않은 창작 문구 32개**를 제공합니다. `phrases.txt`를 확장할 수 있습니다.

## Android Studio에서 열기

압축을 풀고 `nunidam-android` 폴더를 **Open**으로 엽니다. 첫 Gradle 동기화에는 인터넷이 필요합니다. 이 ZIP은 오프라인 빌드용 SDK·Maven 캐시를 포함하지 않습니다.

| 구성 | 고정 버전 |
|---|---|
| JDK / Java 소스 | 17 |
| Gradle Wrapper | 8.13, 배포 파일 SHA-256 검증 |
| Android Gradle Plugin | 8.11.1 |
| compileSdk / targetSdk | 36 / 36 |
| minSdk | 23 |
| Android SDK Build Tools | 35.0.0 |
| Room | 2.8.4 |
| WorkManager | 2.11.0 |
| ML Kit 번들 얼굴 검출 | 16.1.7 |

SDK Manager에서 Android SDK Platform 36, Build Tools 35.0.0, Platform Tools를 설치하고 Gradle JDK를 17로 지정하세요. Android Studio가 `local.properties`를 생성합니다. SDK 경로와 서명 키는 배포 ZIP에서 제외했습니다.

macOS / Linux:

```sh
chmod +x gradlew
./gradlew clean :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows:

```bat
gradlew.bat clean :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

출력 APK는 `app/build/outputs/apk/debug/app-debug.apk`입니다. 기기를 USB 디버깅으로 연결한 개발 환경에서는 `adb install -r app/build/outputs/apk/debug/app-debug.apk`로 설치할 수 있습니다.

실제 검증 결과는 [`docs/VERIFICATION.md`](docs/VERIFICATION.md)에 있습니다. 에뮬레이터·실기기 설치, 장시간 구동, 실제 Wi-Fi 업로드 시험을 통과했다는 의미는 아닙니다.

## 보관 규칙

- 앱은 원본에 쓰거나 원본을 지우지 않습니다. 앱 전용 디렉터리에 최적화한 JPEG 사본을 만듭니다. 원본 백업 프로그램이 아닙니다.
- 동일 원본 바이트는 하나로 합칩니다. 휴지통 사진을 직접 다시 가져오거나 복원하면 수동 보관 사진으로 보호됩니다.
- 저장한 사본은 원본 EXIF 전체를 보존하지 않습니다. 촬영일은 DB에 별도 보관하고 GPS 메타데이터는 사본에 복사하지 않습니다.
- PNG 투명도, 동영상·움짤의 애니메이션은 보존하지 않습니다. HEIC 등 추가 형식은 기기의 디코더에 따라 다릅니다. JPEG/PNG 정지 사진으로 사용하세요.
- 폴더 동기화 중 오류·부분 목록·권한 만료·빈 목록은 대량 삭제 근거로 삼지 않습니다. 즐겨찾기와 수동 보관 사진을 보호합니다. 폴더 원본 내용 변경으로 생긴 이전 버전도 보수적으로 남겨둡니다.
- 휴지통에 들어간 사진은 사용자 영구 삭제 전까지 남습니다. 원본이 여전히 동기화 폴더에 있는 사진을 영구 삭제하면 다음 동기화 때 다시 가져올 수 있습니다.
- 설정 JSON에는 사진, 사진별 기록, 폴더 URI 권한, 웹훅 주소가 없습니다. **앱 삭제·앱 데이터 초기화 시 앱의 사본과 기록도 사라집니다.**

## 운영 시 알아둘 점

야간 감광·픽셀 이동·충전 웹훅은 발열, 잔상, 배터리 상태를 보장하지 않습니다. 스마트 플러그를 사용한다면 앱이 중단되어도 플러그 자체 일정으로 충전이 복구되도록 설정해야 합니다. 이 보조 기능은 DreamService나 앱 종료 상태에서 실행되지 않습니다.

QR 관리 화면은 개인 LAN용 HTTP입니다. 인터넷에 포트를 공개하지 마세요. 연결 토큰, 태블릿 승인, 만료 시간을 사용하지만 전송 구간 자체가 TLS로 암호화되는 것은 아닙니다. 공개 Wi-Fi보다 신뢰하는 개인 네트워크에서 사용하세요.

## 소스 구성과 확장

- `app/src/main/java/co/kr/nuni/dam/`: 앱, DB, 이미지 파이프라인, 화면, 동기화, QR 서버
- `app/src/main/assets/transfer.html`: 외부 의존 파일이 없는 스마트폰 관리 페이지
- `app/src/main/assets/phrases.txt`: 기본 창작 문구
- `app/src/test/`: Android 프레임워크에 의존하지 않는 정책·크롭·스트림 테스트
- `app/schemas/`: Room 스키마. DB 변경 시 마이그레이션을 추가해야 합니다.
- `docs/ARCHITECTURE.md`: 실행 흐름·파일별 책임·확장 지점
- `docs/RELEASE_CHECKLIST.md`: 실기기 확인 항목
- `docs/MONETIZATION.md`: 유무료 분리·Play 결제 후속 작업
- `THIRD_PARTY_NOTICES.md`: 직접 의존성 및 라이선스 안내

이 프로젝트의 자체 소스는 MIT 라이선스입니다. ML Kit를 포함한 제3자 SDK의 코드·모델·상표에는 각 제공자의 조건이 적용됩니다.
